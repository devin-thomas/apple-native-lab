# Showcase 05 — Work that survives interruption

## Audience payoff

Choose a permitted media source, capture or import, inspect timing, start a finite export, background or cancel it, and inspect the resulting checkpoint and final receipt.

## Demonstration contract

Start from a named fixture and declared device configuration. Show the actual action, result, and operation receipt before opening the mechanism inspector. Repeat one meaningful failure or unavailable path. End by restoring demo-owned state. Record only approved media and attach the corresponding evidence run.

## Boundaries

The demonstration must show actual expiration/cancellation behavior rather than implying an unlimited background process.

This is a proposed walkthrough, not a completed recording or a claim that all listed components are implemented.
