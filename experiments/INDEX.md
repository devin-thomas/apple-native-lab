# Experiment catalog


48 bounded experiments. Read the payoff first; follow its two tickets only when dependencies are ready. Everything in this pack is specified rather than implemented.

## System surfaces

### [LAB-001 — Action Atlas](LAB-001-action-atlas.md)

Create a collection, find an item, mutate it, and inspect the same receipt from three entry points. **Wave M1.**

### [LAB-002 — Context Cards](LAB-002-context-cards.md)

Ask about the visible object, then complete a small decision inside a system presentation. **Wave M2.**

### [LAB-003 — Shortcut Workbench](LAB-003-shortcut-workbench.md)

Turn the lab into a small typed automation toolbox, not a collection of launch-app commands. **Wave M2.**

### [LAB-004 — Surface Deck](LAB-004-surface-deck.md)

One reversible session state appears in a widget, a Control, and the main app. **Wave M1.**

### [LAB-005 — Live Session Beacon](LAB-005-live-session-beacon.md)

Follow a real finite export or rehearsal with a cancel button and honest progress. **Wave M2.**

### [LAB-043 — Respectful Attention](LAB-043-respectful-attention.md)

Compare an ordinary reminder, an app Focus filter, and a user-authorized alarm without spamming the system. **Wave M3.**
