# LAB-037 fictional home

Original fixture for the Home Scene Sandbox. Identifiers match `FictionalHome` in
`Packages/LabFeatures/Sources/HomeSceneSandbox`. The hallway lamp starts disconnected so a
partial scene failure is deterministic. Locks, doors, alarms, and heating are present only to
prove default exclusion. No real accessories, accounts, or homes are represented.

Open **Home Scene Sandbox** from the Mac sidebar (⌘9) or its catalog page on Mac/iPhone.
Adjust the lamps' power and brightness, review the preview, then choose **Commit selected lights**.
With **Include hallway lamp** enabled, the disconnected hallway lamp fails and the overall scene
is unsuccessful; the living lamp still changes. Turn that option off to run a successful
one-lamp scene. **Reset Demo** restores lamp defaults and this experiment's run note, retaining
receipts and other records. Live home access is unavailable in this build.
