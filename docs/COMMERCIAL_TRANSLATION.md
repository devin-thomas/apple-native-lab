# From a lab to a commercial product

This document identifies reusable mechanisms, not guaranteed business opportunities or approved distribution paths.

| Lab combination | Plausible product category | What the lab proves | What remains separate |
|---|---|---|---|
| Share intake + typed proposals + documents | Professional capture/workflow tool | Bounded import and review mechanics | Customer auth, retention policy, service reliability, support |
| Speech + native playback + continued export | Creator/media utility | Local timing, editing, playback, checkpoint behavior | Media rights, codec/device coverage, storage operations |
| Room ledger + object capture + accessibility | Inventory/exhibit/planning utility | Spatial annotations and alternate accessible views | Measurement claims, customer privacy, survey accuracy, content rights |
| Local constellation + TV stage + Watch relay | Venue/training/installation companion | Explicit pairing, roles, synchronization, recovery | Fleet deployment, hostile-network testing, on-site operations |
| Custom audio recognition + contextual cards | Exhibit, education, branded-media companion | Matching an authorized prerecorded catalog | Catalog rights, updates, discovery UX, privacy disclosures |
| Wallet + App Clip + trust | Event/retail handoff | Preview, invocation, scoped action boundaries | Signing service, fraud prevention, policy and entitlement approval |
| Accessory setup + safe command protocol | Physical-product companion | Pairing, supported commands, revocation | Hardware certification, firmware updates, vendor SDKs, manufacturing |
| PTT / CarPlay / Screen Time spikes | Category-specific system integration | Correct lifecycle and unavailable paths | Managed approval, infrastructure, abuse prevention, production review |

A commercial extraction should take the smallest well-tested component, not fork the whole lab UI. Retain provenance, error behavior, accessibility, and consent. Remove demo data and debug-only affordances deliberately. Reassess whether a backend is truly required instead of inheriting one from a hypothetical future.

Pricing, App Store rules, commerce classification, entitlements, and API terms may change. Review current official requirements for the intended business before a real launch. No local test purchase, unsigned pass preview, simulated access-control state, or fixture backend constitutes commercial authorization.
