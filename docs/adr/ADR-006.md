# ADR-006 — Separate durable, live, and continuation semantics

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

Use optional CloudKit for records, paired active transport for low-latency sessions, and Handoff for context. Watch relay and Wi-Fi Aware are explicit adapters rather than universal transport assumptions.

## Rationale and consequences

The architecture has more than one transport abstraction because their lifetime, ordering, consistency, and authorization promises are different.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
