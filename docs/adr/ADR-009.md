# ADR-009 — 26-family core with isolated 27-generation adapters

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

Plan a broad 26-family core using the current 27-family toolchain; exact versions and API availability are pinned in bootstrap, not guessed in the planning pack.

## Rationale and consequences

Availability gates and fallback paths require deliberate compilation boundaries. A 27-only feature can still be explored without lifting the entire core floor automatically.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
