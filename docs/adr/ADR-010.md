# ADR-010 — Static modules, not downloaded executable plugins

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

Register experiment modules at compile time. Runtime configuration may select data and allowed behavior but cannot load arbitrary scripts, native code, or model-provided executable commands.

## Rationale and consequences

New capabilities need a reviewed build, while fixtures and safe data remain flexible. This reduces distribution and authorization ambiguity.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
