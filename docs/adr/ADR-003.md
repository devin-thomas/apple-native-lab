# ADR-003 — Local-first fixtures and optional services

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

CoreLocal is useful with original bundled fixtures and local persistence. Cloud sync, external inference, and managed-capability experiments remain separate profiles.

## Rationale and consequences

New users can learn without account infrastructure. Optional integrations require explicit setup and cannot dictate the core data model or startup flow.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
