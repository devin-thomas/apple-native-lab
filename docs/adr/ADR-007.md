# ADR-007 — AI proposes; deterministic code commits

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

Typed generation and tools produce validated drafts or scoped reads. The baseline requires human review before sensitive state changes and never silently switches to an external model route.

## Rationale and consequences

The happy path may include an additional review step. In exchange, the same application works with manual entry and remains inspectable when a model is wrong.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
