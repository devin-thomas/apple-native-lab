# ADR-004 — Operations own authorization, idempotency, and receipts

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

Every adapter calls one typed application service. Requests and results are persisted atomically with local mutations; sensitive commits recheck short-lived scope.

## Rationale and consequences

System surfaces and model tools do not get a privileged business-logic shortcut. More adapters increase test coverage needs, not duplicated behavior.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
