# ADR-005 — Capability gates are runtime evidence, not model-name lists

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

Represent each requirement independently and expose unknown/unverified states. Compilation, permission, assets, service eligibility, and device verification are separate.

## Rationale and consequences

Capability UI is slightly richer, but new OS/device configurations degrade honestly rather than pretending a newer product name guarantees support.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
