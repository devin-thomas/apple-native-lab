# ADR-008 — Source-first MIT distribution and evidence-based releases

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

Use the MIT license for project-owned public code and documentation. Distribute only approved assets under their own recorded terms. Source builds come first; signed binaries are advertised only after real install verification.

## Rationale and consequences

Commercial reuse is straightforward without promising rights in third-party SDKs/media. Each distribution lane has its own setup and compatibility evidence.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
