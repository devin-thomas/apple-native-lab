# ADR-015 — Observe model routes without opening a cloud adapter

Status: accepted 2026-09-30 (LAB-011-A).

## Decision

CoreLocal's Model Routing Observatory reads on-device availability and explains PCC gates, but uses a refusing transport. Its preview describes the lab's proposed request fields, not a captured Apple wire payload. Program eligibility includes the download threshold; source builds claim neither that eligibility nor permitted distribution. Every unknown gate fails closed. The optional live cloud adapter and paid providers remain absent.

Local fallback produces a labeled deterministic text summary or accepts a manual answer. Usage records contain field names, counts, route, and outcome only. A summary stays in the session until a person reviews the target and explicitly approves a demo annotation. That annotation proposes as the model tool and commits as the app UI through the existing operation service. Reset clears the observatory's session state and restores local-only policy; approved annotations remain in the store and retain their domain undo receipt.

Consent covers one exact field preview and one cloud attempt. Policy or eligibility changes invalidate it. A transport failure or cancellation after admission cannot prove that an external delivery did not occur; the outcome says delivery is unconfirmed.

## Validation

`ModelRoutingTests` exercises closed and unknown gates, quota, one-attempt consent, cancellation, privacy, duplicate operations, stale revisions, and denied model-tool commits. `ModelRoutingHostTests` exercises review before a SQLite commit and session reset in the Mac host. Actual run results are recorded in LAB-011-A; no live cloud send is claimed.
