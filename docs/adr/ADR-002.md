# ADR-002 — Native hosts with a shared domain, not a universal screen

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

Use SwiftUI hosts with narrow platform-specific interoperability. Share models, operations, validation, and appropriate UI primitives, but design interaction per device.

## Rationale and consequences

Some UI code is duplicated deliberately to respect keyboard, focus, touch, and glanceability. This is preferable to a lowest-common-denominator interface.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
