# ADR-016 — Wallet Moment ships an unsigned fallback and an injected signing boundary

Status: accepted 2026-09-30 (LAB-038-A).

## Decision

CoreLocal shows an original unsigned event pass at fixture clocks and saves a local event card through the host's authorization and receipt path. It does not link PassKit, load signing credentials, invoke an executable, or contact a signing service. Signing is unavailable by default. An operator-specific adapter can be injected separately; it owns consent, transport, resource limits and cancellation. No such live adapter is supplied by this ticket.

The shared seam validates the definition, refuses cancelled requests, bounds returned data to 2,000,000 bytes, and requires a ZIP local-header prefix. These checks are not archive or signature verification. Test doubles are explicitly labeled; no fixture artifact is claimed to be a valid Wallet pass. Wallet installation, real signing and system-managed Watch display remain qualification gates.

## Rationale and consequences

Signing credentials belong to the operator environment. A shared process runner would add arbitrary executable invocation to the client, block an actor, and fail to compile on iPhone. An injected boundary preserves a useful account-free fallback on Mac and iPhone without adding a capability or hidden service. A future live adapter needs its own configuration and evidence before its output is described as signed or installable.

Sample cards use the user namespace because demo collections are reserved by the store. Reset sample card explicitly archives only the current session's fixture card through the host's scoped destructive grant, leaving other cards and collections intact. The empty event collection remains reusable. The global Reset Demo does not remove user-namespace event cards.

## Validation

`PassSigningTests` cover default unavailability, injected fixture provenance, rejected non-archive and oversized output, and cancellation. `EventCardOperationTests` cover authorization, receipt replay, stale state and confined reset. `WalletMomentHostTests` exercises save, duplicate save, update and reset through an isolated SQLite host store. Results are recorded in the ticket completion record.
