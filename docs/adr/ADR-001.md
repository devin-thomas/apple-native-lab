# ADR-001 — One public core, independently composed downstream apps

Status: accepted planning default; amend through a later decision before changing behavior.

## Decision

Keep reusable Swift packages independent of any consuming application identity or data. Downstream apps depend on these packages; the public host never depends on downstream sources, flags, or credentials.

## Rationale and consequences

This preserves a clean standalone build and makes reusable capability work portable. Consumers maintain their own targets, namespaces, and releases; shared source does not imply shared app data.

## Validation

The relevant foundation and release tickets must demonstrate this decision. This record does not imply that implementation has already occurred.
