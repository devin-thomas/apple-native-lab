# Pick Up Here

Qualification is a fixture replay through the Mac host, iPhone simulator host, and package operations. No two-device Handoff, physical iPhone, or iPad run is recorded. The simulator session replay does not prove Handoff delivery.

Open Pick Up Here from the Mac sidebar or View › Pick Up Here (⌥⌘1). On iPhone, open its catalog page and choose Open Pick Up Here.

1. Choose Add Sample Draft. It adds the original Workbench layout to a collection of your own. Select section 2 of 3.
2. Choose Copy Continuation Link. Paste it into Continuation link on a destination lab that does not hold this draft, then choose Continue from Link. The result asks to import; it contains no section text.
3. On the source, choose Copy Document. Paste that separate copy into Continuation document on the destination and choose Import Document. The import produces an app-UI receipt and resumes at section 2. Importing again adds no second draft.
4. Choose Revoke Access on the selected draft, then Continue from Link. The continuation text disappears; the editor displays the revocation explanation. This is a window-local demonstration of revoked access, not a platform file-permission change. Allow Access permits a later read.
5. If the destination draft has changed to fewer sections, continuing clamps the saved index into its current text and explains the changed position. Qualification tests shorten the note through the same authorized operation service.
6. Clear Continuation drops the advertised hint, incoming text fields, and result. It retains stored drafts. Reset Demo also retains the imported sample because it is user data after import.

Advertise asks the system to advertise an activity. Handoff carries an identifier, revision, and section; it does not carry the draft. Delivery still requires compatible system configuration and the same developer Team ID. It has not been qualified between devices. The `nativelab://continue` fallback is copied and pasted inside the app; system URL dispatch and universal links are not implemented or claimed.

The replay uses only the original fixture in `Fixtures/LAB-016/`. No screenshot or exported user document accompanies this qualification. The explicit document contains draft text; copy it only when you intend to transfer that text. Hints use a fixed activity title, omit draft text and title, and disable search/public indexing, streams, and webpage URLs. No account connection or network request is needed for the fallback.

Static accessibility review: actions have text labels and hints, the section picker has a label, and the phone marks the chosen draft as selected. The Mac provides the navigation shortcut above but no dedicated menu commands for individual continuation actions. The result sentence appears in both the action area and incoming area, which may cause repeated announcements. VoiceOver, Voice Control, Full Keyboard Access, large text, reduced motion, and iPad layout remain not-run; source inspection is not an accessibility pass.
